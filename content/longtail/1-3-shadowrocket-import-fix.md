# 1-3. Shadowrocket (小火箭) 节点导入失败怎么办？3分钟排查指南

作为 iOS 和 iPadOS 平台上历史最悠久、装机量最大的全能代理工具，Shadowrocket（因其图标被用户亲切地称为“小火箭”）以极低的系统资源占用和丝滑的协议兼容性著称。然而，很多新手在使用小火箭导入机场订阅链接时，经常会遇到“节点列表一片空白”、“导入没有任何反应”或频繁报错“Invalid URL”的尴尬情况。

如果你确认手头的订阅地址没有过期，但在多次尝试后依然无法拉取节点，其根源往往出在本地网络环境劫持、格式编码冲突或应用权限限制上。在开始逐一排查前，建议你先阅读《[2026全网高性价比机场推荐与便宜梯子防坑指南](/pillar-1)》，确认当前所使用的机场服务商底层网络处于正常运行状态。本文将为你梳理 5 种最核心的故障诱因，并在 3 分钟内带你彻底解决导入问题。

---

## 一、排查一：订阅链接格式受损与空格污染（最常见）

90% 的导入失败，问题都出在手机复制长链接时的“无意识格式污染”。

### 排查步骤：
1. **检查链接首尾空格：** 从微信、QQ 或移动端备忘录复制链接时，系统经常会自动在链接末尾附带一个不可见的“空格”或换行符。小火箭在解析带有空格的 URL 时会直接中断。
2. **清洗链接：** 将订阅链接先粘贴到手机自带的“备忘录”中，用光标拉到最前和最后，手动删除前后的多余空格，确认是以 `https://` 开头。
3. **正确填入路径：**
   * 打开小火箭，点击右上角的 **“+”** 号。
   * 点击第一项“类型”，必须选择为 **“Subscribe（订阅）”**（不要误选为 Shadowsocks、Vmess 等单节点协议）。
   * 在“URL”一栏中粘贴清洗后的纯净链接，在“备注”中随手输入机场名称，最后点击右上角的 **“完成 (Done)”**。

---

## 二、排查二：本地移动网络对订阅域名的 DNS 阻断

有时候小火箭并没有故障，而是国内运营商（尤其是中国移动宽带/移动 4G/5G）对机场的“订阅下发域名”执行了局部 DNS 污染，导致手机在没有梯子的情况下根本连不上该域名去下载配置文件。

### 解决对策（破除死循环）：
1. **切换网络环境重试：** 如果当前连着家庭 Wi-Fi，请关闭 Wi-Fi 切换到手机蜂窝移动网络（或者反过来，切换至联通/电信网络的热点）重新下拉刷新。
2. **开启小火箭 DoH 安全 DNS：**
   * 进入小火箭底部 **“设置 (Settings)”** -> **“DNS”**。
   * 添加并启用加密公共 DNS（如阿里公共 DNS `https://dns.alidns.com/dns-query` 或 Cloudflare `https://1.1.1.1/dns-query`），防止运营商在底层篡改域名解析。
3. **向机场获取备用订阅域名：** 登录机场后台，大部分成熟服务商都会提供多条经过 CDN 防封加速的“备用订阅链接”，更换一条重新导入。

## 三、排查三：iOS 系统权限限制（无线局域网权限未授权）

在国行 iPhone 首次安装小火箭后，iOS 系统会弹窗询问“是否允许 Shadowrocket 使用数据网络”。部分用户在匆忙中误点了“不允许”或“仅无线局域网”，导致小火箭在特定环境下根本没有联网权限。

### 检查路径：
1. 打开 iPhone **“设置”** -> 向下滑动找到 **“Shadowrocket”**。
2. 点击 **“无线数据”**。
3. 确保将其勾选为 **“无线局域网与蜂窝数据”**。
4. 如果找不到该选项，请进入“设置” -> “通用” -> “传输或还原 iPhone” -> “还原” -> “还原网络设置”（不会丢失数据，仅重置网络授权状态）。

---

## 四、排查四：系统时间未同步导致安全证书握手失败

现代所有机场订阅均基于 HTTPS 强加密协议传输。如果手机的本地时间与国际标准时间（UTC）存在超过 1–2 分钟的偏差，设备在与机房握手时就会因为“SSL 证书时间不匹配”而强行中断连接。

### 修复方法：
1. 打开 iPhone **“设置”** -> **“通用”** -> **“日期与时间”**。
2. 确保勾选开启 **“自动设置”**。
3. 切换一次飞行模式，强制手机基站重新同步毫秒级标准时间后再尝试更新订阅。

---

## 五、终极备用方案：通过扫码或单节点导入跳脱困境

若上述方法由于网络封锁在当前环境下依然无法刷新列表，可以通过以下备用路径快速上线：

### 1. 扫码一键导入（无需复制链接）
1. 用电脑、平板或另一台设备登录你的机场控制面板。
2. 找到“一键导入订阅”附近的 **“Shadowrocket 二维码”**。
3. 打开手机小火箭，点击左上角的 **“扫码图标”**，直接对准屏幕扫描，客户端将自动识别协议并将全量节点瞬间写入本地，绕过繁琐的文本粘贴流程。

### 2. 导出单个节点应急
若订阅链接完全被封，可以在机场控制面板中点击“节点列表”，选择单个香港或日本节点的“节点二维码”或“链接”，先单独导入一个可用节点。连上该节点翻墙成功后，再在小火箭里右滑订阅卡片点击“更新”，即可利用该节点的翻墙通道顺畅更新完整订阅。
