# 1-5. V2rayN 怎么用？Windows 电脑科学上网零基础图文教程

对于 Windows 用户而言，除了 Clash 架构之外，**v2rayN** 绝对是科学上网领域生命周期最长、协议支持最全、性能消耗最低的传奇开源客户端之一。无论你手头的机场使用的是老牌的 Shadowsocks/VMess，还是 2026 年最新主流的 VLESS Reality、Hysteria2 或是 Trojan 协议，v2rayN 都能做到完美通吃与底层极速调用。

更重要的是，v2rayN 代码完全托管在 GitHub 上公开透明，绝无任何暗藏的后门与流氓插件。在开始上手配置之前，请先准备好你的机场专属订阅链接；若你仍在寻找高性价比且全协议适配的节点，建议先阅读这篇权威测评指南：《[2026全网高性价比机场推荐与便宜梯子防坑指南](/pillar-1)》。本文将为你拆解从软件安全下载、订阅一键导入到节点延迟测速的全流程实操。

## 一、环境准备与纯净软件下载

v2rayN 是基于微软的 .NET 架构开发的绿色免安装软件，正确的下载姿势至关重要。

### 1. 认准官方开源发布地址
*   **官方唯一下载源：** 认准 GitHub 官方开源仓库 `2dust/v2rayN/releases`。
*   **下载版本选择：** 
    *   页面通常提供两种包：推荐下载自带运行环境的完整整合包（例如 `v2rayN-With-Core.zip` 或 `v2rayN-windows-64-With-Core.zip`）。该版本已预置了 Xray 与 sing-box 核心内核，免去了后续手动下载内核配置的麻烦。
*   **解压建议：** 下载完成后，将压缩包解压到一个固定的英文路径文件夹中（例如 `D:\Software\v2rayN`），**千万不要直接在压缩包内双击运行**，也不要把目录放在带有中文或特殊字符的路径下。

### 2. 必备前置运行库（若双击无法打开）
如果双击 `v2rayN.exe` 没有任何反应或提示缺少依赖，说明你的 Windows 系统缺少微软官方环境支持。请前往微软官网下载并安装 **“Microsoft .NET 6.0 Desktop Runtime (x64)”** 或更高版本即可解决。

## 二、从零配置：三步实现极速科学上网

### 步骤一：导入机场订阅链接
1. 双击运行解压目录下的 `v2rayN.exe`，如果弹出防火墙网络提示，一律点击“允许访问”。
2. 软件运行后，会自动最小化到屏幕右下角的系统托盘区（一个带小深蓝色的“V”字图标）。双击该图标调出主界面。
3. 点击主界面顶部菜单栏的 **“订阅分组”** -> 选择 **“订阅分组设置”**。
4. 在弹出的窗口左下角点击 **“添加”**：
   *   **别名：** 随便填写你的机场名字（如：`我的专线机场`）。
   *   **可选地址 (url)：** 完整粘贴你在机场后台复制的专属订阅链接。
5. 点击 **“确定”** 保存并退出设置窗口。
6. 再次点击顶部菜单栏的 **“订阅分组”** -> 点击 **“更新全部订阅 (不通过代理)”**。
7. 稍等 2–5 秒，主界面空白处将瞬间刷出一整排整齐的海外节点列表。

## 三、节点测速与选优（真连接延迟测速）

面对刷新出来的数十个节点，新手往往不知道选哪一个。请注意：**不要看没有参考价值的 Ping 延迟，必须测试“真实下载与连接延迟”。**

### 实操选优步骤：
1. 在主界面的节点列表中，按键盘快捷键 **`Ctrl + A`** 全选所有节点。
2. 单击鼠标右键，在右键菜单中选择 **“测试服务状态”** -> 点击 **“测试服务器真连接延迟 (按回车或按键)”**（快捷键为 `Ctrl + R`）。
3. 软件会逐个模拟向 Google 服务器发起数据连接探测：
   *   **数值为具体数字（如 45ms、80ms）：** 绿色或蓝色数字代表节点健康可用，数值越低代表连接速度越快。
   *   **显示为“-1”或“Timeout”：** 代表该节点当前失效或无法接通。
4. 鼠标左键双击一个延迟最低的香港或日本节点（或者按回车键选中），该节点左侧会出现一个蓝色勾选标志，代表将其设为**当前活动节点**。

## 四、核心：开启系统代理与选择路由规则

配置完节点后，最后一步是让电脑系统正式接入代理通道。

### 1. 开启系统代理
在 v2rayN 底部任务栏状态区，找到 **“系统代理”** 下拉选框：
*   将其从默认的“清除系统代理”切换选择为 **“自动配置系统代理”**。
*   此时屏幕右下角托盘区的“V”字图标会**从蓝色变为鲜艳的粉红色**，代表整机代理已成功接管流量。

### 2. 路由模式设置（防止国内软件卡顿）
在底部的 **“路由”** 下拉选框中：
*   **强烈建议选择：“绕过大陆 (Whitelist)” 或 “绕过大陆及局域网”**。
*   **作用：** 访问百度、淘宝、微信等国内流量自动直连原速访问；只有在访问 YouTube、Google 等海外站点时才自动走翻墙节点，彻底避免浪费机场流量。

## 五、高频疑难杂症排查 (FAQ)

### Q1: 更新订阅时报错“基础连接已经关闭”或“未能解析此远程名称”？
这是因为本地运营商对机场的订阅域名产生了临时 DNS 污染阻断。
*   **解决对策：** 用手机开启蜂窝网络热点，将电脑连上手机热点后重新点击“更新订阅”；或者先在机场官网手动复制一两个单个节点链接，在主界面按 `Ctrl + V` 导入并连上，随后在“系统代理开启”的状态下点击“更新全部订阅 (通过代理)”。

### Q2: 电脑右下角图标已经变成粉色，但依然打不开 Google？
1. **排查电脑时间：** 90% 的连不上都是因为系统时间误差。打开 Windows 设置 -> 日期和时间 -> 点击“立即同步”，确保毫秒不差。
2. **排查节点本身：** 重新按 `Ctrl + R` 测试真连接，如果所有节点都显示“-1”，说明当前网络环境封锁了该协议端口，或你的套餐已欠费到期。

### Q3: 不用翻墙时，怎么彻底关闭？
使用完毕后，只需在电脑右下角托盘区右键点击“V”字图标，选择 **“退出”**，软件在退出时会自动清理注册表中的代理项，恢复你的本地正常网络连接。
