# 1-14. 机场节点全部超时/Timeout？一文教你排查本地网络与 DNS 污染

几乎每一位经常使用科学上网工具的用户，都曾经历过这种令人抓狂的绝望时刻：昨天深夜明明还在顺畅追剧、查资料，今天早上一推开笔记本，或者刚下地铁打开手机，客户端里几十个甚至上百个原本绿油油的海外节点，**竟然全军覆没，测速一律显示“-1”、“Timeout”或刺眼的鲜红色**。

遇到这种情况，许多新手的第一个反应就是“完了，机场是不是又跑路了？”。但根据一线技术维护的统计数据，超过 80% 的“全线超时”并非机房物理关停，而是出在本地系统时间误差、本地运营商 DNS 投毒或者代理软件本身的注册表死锁上。在急着找客服对线之前，建议你先阅读这份底层网络通识指南：《[2026全网高性价比机场推荐与便宜梯子防坑指南](/pillar-1)》，建立起全局网络判断框架。本文将带你通过一套结构化的 5 步排查法，在几分钟内精准定位病灶并恢复网络。

---

## 一、排查第一步：检查本地物理网络与系统时间的“毫秒级误差”

这是最常被小白忽视、但触发率最高的致命根源。

### 1. 系统时间误差（精确度低于 60 秒）
现代主流翻墙协议（尤其是 VMess、VLESS Reality、Hysteria2 以及带 TLS 握手的节点）在底层通信时，强制校验客户端与海外服务器之间的系统时间戳。
*   **触发机理：** 如果你电脑或手机的系统时钟因为主板电池没电、长久离线或时区错乱，与全球标准 UTC 时间偏差超过 **90 秒**，服务器就会判定该连接为重放攻击（Replay Attack）并直接强行阻断，导致**所有节点无一例外全部超时**。
*   **修复动作：** 
    *   Windows 用户：打开设置 -> 时间和语言 -> 日期和时间 -> 点击 **“立即同步”**。
    *   手机用户：进入设置 -> 通用 -> 日期与时间 -> 确认开启 **“自动设置”**。

### 2. 本地真实网络是否本身已断网？
关掉代理客户端，先尝试打开国内的百度（baidu.com）或哔哩哔哩。如果连国内网站都打不开，说明是你家的宽带光猫断网、欠费，或者手机欠费停机，与梯子毫无关系。

---

## 二、排查第二步：登录机场后台核验账户真实状态

在确认本地设备正常后，用手机浏览器（直连或流量模式）登录你的机场官网后台仪表盘：
1.  **核对套餐状态与流量余额：** 很多时候是因为月度结算日已到，或者不知不觉下载了大文件将月流量全部跑尽，账户触发了欠费停机。
2.  **查看官方公告栏（Notice）：** 查看是否有“紧急机房割接维护”、“核心专线上游光缆抢修”等突发事件通告。

---

## 三、排查第三步：清理本地 DNS 缓存并防范运营商投毒

国内运营商（特别是移动宽带和部分二级宽带）经常会对机场的入口 IP 执行瞬时域名污染或阻断。

### 实操修复：
*   **Windows 电脑清空 DNS 缓存：**  
    按键盘快捷键 **`Win + R`** 输入 `cmd` 回车，在黑色终端中输入并执行以下命令：
    ```bash
    ipconfig /flushdns
    ```
    提示“已成功刷新 DNS 解析缓存”后，重新回到代理客户端内按快捷键测速。
*   **切换手机热点测试：**  
    将电脑临时连接手机开出的 4G/5G 个人热点。如果连上热点后所有节点瞬间恢复变绿，说明是你家的有线宽带运营商对该机场的入口机房路由产生了临时故障阻断。

---

## 四、排查第四步：排查系统代理端口冲突与 TUN 网卡死锁

如果你使用的是 Clash、v2rayN 或 Clash Verge，非正常关机（如电脑直接拔电源、蓝屏或笔记本合盖休眠）很容易导致客户端残留的虚拟网卡或系统代理设置没有被优雅注销。

### 解决对策：
1.  **关闭并重启系统代理开关：** 在 Clash 的 General 页面，手动将 `System Proxy` 开关关闭，等待 5 秒后再重新打开。
2.  **重置注册表代理项（Windows）：**  
    打开电脑“设置” -> “网络和 Internet” -> “代理” -> 确保“使用代理服务器”在手动设置下处于关闭状态，由客户端接管。
3.  **彻底重启客户端：** 在右下角任务栏托盘中彻底“退出 (Quit)”软件，在任务管理器中确认没有 `clash-core` 残留进程后，重新以管理员身份启动。

---

## 五、排查第五步：更新订阅或使用备用单节点

如果上述步骤均正常，说明当前的订阅链接所包含的节点 IP 已被集体失效转移：
1. 在客户端内右键点击你的订阅卡片，选择 **“更新订阅 (Update)”**。
2. 若更新报错，登录机场官网复制其提供的“备用应急订阅链接”，重新导入。
